# RateSync 💱

RateSync is a responsive, high-performance financial dashboard and currency converter built with Vue.js. It features a sleek, high-contrast dark mode interface designed to help users monitor live markets, convert between 150+ global currencies, and analyze historical exchange rate trends in real-time.

## ✨ Features

* **Real-Time Currency Converter:** Instantly calculate exchange rates across over 150 fiat and cryptocurrencies with a seamless one-click swap function.
* **Live Market Ticker:** A continuous scrolling header displaying live percentage changes for major global markets and currency pairs.
* **Historical Data Charts:** Interactive line graphs visualizing performance history, featuring adjustable timeframes (1W, 1M, 3M, 6M, 1Y, 5Y).
* **Global Comparison Tool:** Compare a single base currency against a comprehensive global index simultaneously.
* **Personalized Watchlist:** Pin frequently used currency pairs to a dedicated "Favorites" tab to monitor daily fluctuations.
* **Conversion Logging:** Save specific transaction calculations to a persistent log for easy reference and record-keeping.

## 🛠️ Tech Stack

* **Frontend Framework:** Vue.js
* **Styling:** Custom CSS & Bootstrap 5 (Dark theme with neon green accents)
* **Data Visualization:** Chart.js (or equivalent Vue charting library)
* **State Management:** Vue reactivity for managing favorited pairs, conversion logs, and active chart filters
